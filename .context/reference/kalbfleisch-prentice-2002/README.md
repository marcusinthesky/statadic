# The Statistical Analysis of Failure Time Data

Metadata checked on 2026-11-04 against the [publisher](https://onlinelibrary.wiley.com/doi/book/10.1002/9781118032985). The contents identify parametric inference, likelihood construction and AFT topics; the publisher explicitly mentions left-truncation coverage.

This is a supporting textbook reference for the Weibull/lognormal AFT study with independent censoring and delayed entry. A complete source-equation review of STATADIC's likelihood, scale conventions and observed-information inference was not performed. This second edition is not represented as the seminal publication of AFT estimation.
