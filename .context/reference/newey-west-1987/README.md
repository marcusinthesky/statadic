# A Simple, Positive Semi-Definite, Heteroskedasticity and Autocorrelation Consistent Covariance Matrix

Metadata verified on 2026-11-04 against the publisher-deposited
[Crossref record](https://api.crossref.org/works/10.2307/1913610) and the authors'
[NBER record](https://www.nber.org/papers/t0055), whose published-version entry
confirms the full 703–708 page range. The working paper is dated 1986; the journal
article is 1987.

Equation (5) of the [original working paper](https://www.nber.org/system/files/working_papers/t0055/t0055.pdf)
uses Bartlett weights declining with lag. This supports the methodological
attribution of Bartlett HAC, rather than every kernel, bandwidth selector,
degrees-of-freedom correction or finite-sample reference law in STATADIC.
