# Testing for Autocorrelation in Dynamic Linear Models

Derives a Lagrange multiplier test for autoregressive and moving-average residual dependence that remains valid with lagged dependent regressors. STATADIC's `BreuschGodfrey(lags)` reports `n R²` of the residual-lag auxiliary regression. Metadata was checked against the publisher-deposited Crossref record on 2026-11-08. The source does not establish finite-sample calibration of the asymptotic reference used here.

[Primary source](https://doi.org/10.1111/j.1467-8454.1978.tb00635.x).
