# Distance covariance in metric spaces

Metadata checked against the [published paper](https://rdlyons.pages.iu.edu/pdf/dcov-published.pdf), p. 3284. Section 3, equation (3.1), p. 3291 defines negative type by the zero-sum weighted distance inequality; pp. 3292–3293 discuss Euclidean embeddings and p. 3293 equation (3.3) gives the probability-measure inequality. The Gaussian projection proof in Lean is a different proof of the finite result.
