# A note on studentizing a test for heteroscedasticity

Shows that the original Breusch–Pagan statistic is sensitive to non-Gaussian kurtosis and proposes the studentized `n R²` form. STATADIC uses it as the default `BreuschPagan()` and in the White test. Metadata was checked against the publisher-deposited Crossref record on 2026-11-08. The source does not establish finite-sample calibration of the asymptotic reference used here.
