# Risk, Return, and Equilibrium: Empirical Tests

Metadata verified on 2026-11-04 against the
[original publisher](https://www.journals.uchicago.edu/doi/10.1086/260061) and
[original article scan](https://pages.stern.nyu.edu/~wgreene/Econometrics/Fama-Macbeth.pdf).
The scan identifies volume 81, issue 3, May–June 1973, pages 607–636.

This is the seminal source for the named Fama–MacBeth methodology. STATADIC's
generic period-by-period regression interface, unavailable-period handling and
HAC extension do not inherit an unrestricted correctness or inferential
guarantee merely from that attribution. The study must state its unconditional
coefficient target and serial dependence separately.
