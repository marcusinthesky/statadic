# Nonlinear component analysis as a kernel eigenvalue problem

Kernel principal coordinates use the centered kernel eigenproblem. The frozen cross-kernel map uses training centering statistics and retained positive eigenpairs. STATADIC does not infer an inverse/preimage map or smooth eigenvectors at repeated eigenvalues.
