# A Test for Normality of Observations and Regression Residuals

Derives the skewness–kurtosis Lagrange multiplier test of normality for observations and regression residuals with its asymptotic chi-square(2) reference. STATADIC's `JarqueBera()` uses biased residual moments. Metadata was checked against the publisher-deposited Crossref record on 2026-11-08. The source does not establish finite-sample calibration of the asymptotic reference used here.

[Primary source](https://doi.org/10.2307/1403192).
