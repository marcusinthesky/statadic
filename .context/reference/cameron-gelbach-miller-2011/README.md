# Robust Inference With Multiway Clustering

Metadata verified on 2026-11-04 against the
[publisher](https://www.tandfonline.com/doi/abs/10.1198/jbes.2010.07136),
[deposited record](https://api.crossref.org/works/10.1198/jbes.2010.07136) and

must not replace it. Author order is Cameron, Gelbach, Miller.

The original source introduces nonnested multiway cluster covariance for OLS
and nonlinear estimators. STATADIC's inclusion–exclusion terms, separate group
corrections, finite-sample reference distribution and handling of indefinite
covariance require their own implementation review. Citation metadata alone
does not establish coverage or certify those choices.
