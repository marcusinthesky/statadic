# A Reality Check for Data Snooping

Metadata verified on 2026-11-04 against the [primary source](https://www.econometricsociety.org/publications/econometrica/2000/09/01/reality-check-data-snooping) and the [publisher-deposited record](https://api.crossref.org/works/10.1111/1468-0262.00152).
