# A Simple Test for Heteroscedasticity and Random Coefficient Variation

Introduces the Lagrange multiplier test that regresses scaled squared OLS residuals on variance regressors and reports half the explained sum of squares. Its chi-square reference relies on Gaussian errors. STATADIC implements this original form as `BreuschPagan(studentized=False)`. Metadata was checked against the publisher-deposited Crossref record on 2026-11-08. The source does not establish finite-sample calibration of the asymptotic reference used here.

[Primary source](https://doi.org/10.2307/1911963).
