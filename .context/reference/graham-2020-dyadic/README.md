# Dyadic regression

Publication identity checked on 2026-11-04 against the [publisher](https://www.sciencedirect.com/science/chapter/edited-volume/pii/B9780128117712000080) and [author CV](https://bryangraham.github.io/econometrics/downloads/cv_BSG.pdf). [Author manuscript](https://bryangraham.github.io/econometrics/downloads/publications/EconometricsOfNetworksBook/DyadicRegression/Dyadic_M_Estimation_21Aug2019.pdf).

This review explains why shared-node dyads raise distinct estimation and inference issues. It is useful background for whole-network replication in STATADIC's point-risk study. It is not a verified seminal source for the exact pooled/node-fixed-effect implementation or multinomial node-bootstrap schedule; those source matches remain open.
