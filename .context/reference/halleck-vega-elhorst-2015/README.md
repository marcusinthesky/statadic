# The SLX Model

Metadata checked on 2026-11-04 against the [publisher](https://onlinelibrary.wiley.com/doi/abs/10.1111/jors.12188) and [institution-hosted version of record](https://pure.rug.nl/ws/portalfiles/portal/99108393/THE_SLX_MODEL.pdf). The first author's family name follows the publisher's “Halleck Vega” form.

Section 2, equations (8)–(10), derives the reduced-form covariate effect
matrix for a spatial Durbin model. STATADIC proves that, holding the weights
fixed, a finite covariate change is multiplied by this matrix. Its mean
diagonal gives the direct impact and its mean row sum gives the total impact.
