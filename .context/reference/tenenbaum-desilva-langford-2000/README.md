# A global geometric framework for nonlinear dimensionality reduction

The Isomap construction combines neighbourhood edge lengths, graph shortest paths and classical scaling. STATADIC initially uses dense shortest paths, rejects disconnected graphs and requires explicit positive-subspace approximation for material negative inertia. The original asymptotic manifold recovery claim requires additional geometric and sampling assumptions; STATADIC's implementation and reference tests do not establish it.
