# A Simple Sequentially Rejective Multiple Test Procedure

Theorem 1, page 67, proves strong familywise protection for the sequentially rejective Bonferroni procedure. The preceding definition and the proof use the Bonferroni inequality, which also gives the single-step correction. The test-level assumption corresponds to valid marginal true-null p-values; no dependence assumption is required. Source: [article scan](https://www.ime.usp.br/~abe/lista/pdf4R8xPVzCnX.pdf).
