# Some heteroskedasticity-consistent covariance matrix estimators with improved finite sample properties

Publication metadata was checked on 2026-11-04 against the publisher record.
Section 2 of the [author-hosted paper](http://qed.econ.queensu.ca/working_papers/papers/qed_wp_537.pdf)
defines HC1, HC2 and jackknife-derived HC3 corrections; its experiments study
their finite-sample behavior. STATADIC's covariance contract explicitly uses row
leverage corrections and a separately recorded finite-sample multiplier.
Reference distributions remain a separate choice. These sources motivate
evaluation; they do not establish universal small-sample coverage.

A subsequent full-text review also matched the unweighted OLS point formula and
classical residual-variance covariance in Section 2, equations 1–4. The historical
HC3 jackknife expression in equations 12–13 has both a prefactor and a rank-one
recentering subtraction. STATADIC's conventional uncentered leverage-squared HC3
sandwich therefore is not exactly that finite-sample expression. A subsequent
Long–Ervin (2000) manuscript review supplies the conventional formula; the
historical distinction remains explicit in its companion reference and catalogue.
