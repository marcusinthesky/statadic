# Tests for Specification Errors in Classical Linear Least-Squares Regression Analysis

Proposes regression specification error tests that augment the design with functions of the fitted values. STATADIC's `RESET()` adds powers of the fitted values and Wald-tests them with the augmented fit's classical covariance. Metadata was checked against the publisher-deposited Crossref record on 2026-11-08. The source does not establish finite-sample calibration of the asymptotic reference used here.
