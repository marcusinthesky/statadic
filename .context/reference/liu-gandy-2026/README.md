# Kernel Tests of Equivalence

Metadata checked against the [arXiv v2 record](https://arxiv.org/abs/2603.10886v2).
[Section 4.2, Lemma 7 and Theorem 8](https://arxiv.org/html/2603.10886v2)
give an asymptotic multiplier-bootstrap result for MMD of fixed distributions,
using a bounded kernel. The theorem does not establish validity of STATADIC's
percentile energy-distance bootstrap after mixture-weight selection.
