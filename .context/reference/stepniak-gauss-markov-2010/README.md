# From Equivalent Linear Equations to Gauss-Markov Theorem

Theorem 4.1, pp. 4–5, compares the variance of linear unbiased estimators.
For a fixed full-column-rank design, STATADIC proves coefficient unbiasedness
from integrable mean-zero errors. With square-integrable responses and
spherical covariance, it also proves the exact variance gap between an
arbitrary linear unbiased contrast and OLS on general probability spaces.
