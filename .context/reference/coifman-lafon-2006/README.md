# Diffusion maps

Section 2.1 forms the Markov transition kernel by dividing affinities by the row degree. Section 2.2 illustrates it with a squared-distance exponential kernel. STATADIC removes self-edges and allows an input cost table. The two Lean claims concern this finite normalization and its scale invariance.
