# Computing Robust Standard Errors for Within-groups Estimators

Metadata checked on 2026-11-04 against the [publisher](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1468-0084.1987.mp49004006.x) and [author publication list](https://www.cemfi.es/~arellano/). The [original paper's opening page](https://bpb-us-w2.wpmucdn.com/u.osu.edu/dist/7/36891/files/2020/03/Arellano1987OxfordComputingRobustStandardErrorsWithinGroupsEstimator.pdf) specifies exogenous panel regressors, individual effects and arbitrary within-individual error covariance with independent individuals.

This supports the within-estimator/entity-cluster covariance construction. It does not justify STATADIC's selected finite-group correction or residual-df t/F calibration as exact. It also does not license random-effects, between, two-way clustering or Driscoll-Kraay under this single citation.
