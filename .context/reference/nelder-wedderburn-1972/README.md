# Generalized Linear Models

Metadata checked on 2026-11-04 against the [publisher](https://academic.oup.com/jrsssa/article/135/3/370/7110572) and [original paper](https://jhanley.biostat.mcgill.ca/bios601/Likelihood/NelderWedderburn1972.pdf). The issue year is 1972, distinct from the publisher's later digital publication date.

Pages 370-374 introduce exponential-family GLMs, Binomial and Poisson examples, link functions and iterative fitting. This is a primary foundation for STATADIC's binomial-logit and Poisson-log model definitions. It does not establish the correctness of STATADIC's numerical solver, finite-optimum existence certificates, HC corrections or finite-sample normal-Wald coverage. The canonical-inference study evaluates those concrete procedures separately.
