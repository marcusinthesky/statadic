# A Quadratically Convergent Newton Method for Computing the Nearest Correlation Matrix

The introduction states the nearest-correlation problem and describes the positive-part solution at a suitable dual shift. STATADIC measures the diagonal residual there. The registered proofs separate the exact projection certificate from the positive definiteness and diagonal of the subsequently rescaled matrix.
