# Estimating the dimension of a model

Publication metadata was checked on 2026-11-11 against the Crossref record for
the DOI. Derives the large-sample criterion that STATADIC reports as `bic`: minus twice the maximised log likelihood plus the number of estimated parameters times the log of the number of observations entering the likelihood. The parameter count follows the rule recorded for [Akaike (1974)](../akaike-1974/README.md). The criterion's asymptotic justification does not qualify a finite-sample model choice.
