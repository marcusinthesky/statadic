# The determination of the order of an autoregression

Publication metadata was checked on 2026-11-11 against the Crossref record for
the DOI. Introduces the order-selection criterion that STATADIC reports as `hqic`: minus twice the maximised log likelihood plus twice the number of estimated parameters times the log of the log of the number of observations. The paper derives it for autoregressive order; STATADIC applies the same penalty to other likelihood fits, as statsmodels does, with the parameter count recorded for [Akaike (1974)](../akaike-1974/README.md).
