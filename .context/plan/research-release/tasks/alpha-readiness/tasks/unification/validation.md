# Ordination and Regression migration evidence

Implementation starts from `06a7ced` on 2026-11-10. The complete 3,333-line
unification discussion supplied the design constraints. The coordinator retained
API adjudication, shared lifecycle, persistence, inventories and serialized tests;
three delegated arms implemented regression, ordination and geometric regression.

## Implemented contracts

- One `Regression` owns response, terms, law, structure and estimation choices.
  Family results retain their actual capabilities. `Ordination` is a model and a
  directly composable predictor term. Retired constructors have no aliases.
- Linear Gram uses feature SVD. Kernel, distance and shortest-path constructions
  retain their actual reference and query maps; positive-subspace approximation
  is explicit. Disconnected Isomap graphs fail preparation.
- Geometric Regression uses explicit full/reduced designs and supplied schedules.
  Exhaustive Freedman–Lane remains approximate; it acquires no exact-calibration
  tag. Raw-distance inference inherits no squared-Euclidean nuisance model.
- Schema 5 stores one closed Ordination map codec, including nested regression
  designs. The duplicate PCA/PCoA artifact implementation is removed. Supplied
  moments use one `estimate(data, estimator=...)` operation.
- Performance uses the owner's explicit `report` policy. Legacy strict scopes
  retain their original superiority checks. Neutral consumer schema 2 preserves
  exact frozen provenance and rejects old operational names.
