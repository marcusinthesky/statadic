# Simplify the documentation and complete the OLS learning path

## Goal

Keep Sphinx/Shibuya, local serif typography and native marimo. Guide readers
through Start, Tutorials, How-to, Concepts, Reference and Evidence, with
Ordination, Regression, Hypothesis and Report as the public API map.

The coordinator owns shared Sphinx configuration, evidence/output rendering,
integration and serialized verification. Three arms own presentation/browser
checks, editorial structure, and the canonical OLS example/lessons/marimo lab.
No new numerical API, WASM runtime, evidence registry or qualification campaign
is introduced. The 1,541-word entry-path cap remains frozen.

## Acceptance

- [x] Remove decorative artwork and layout compensation while retaining accessible scientific content.
- [x] Separate documentation roles and provide concise references for the four principal APIs.
- [x] Complete the OLS chapter using one executable recipe shared with native marimo.
- [x] Bind displayed outputs and scoped evidence links to their actual sources.
- [x] Pass targeted verification, the required aggregate and rendered browser checks.
