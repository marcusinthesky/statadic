## Review findings and corrections

- Release builds now select the actual installed build interpreter.
- Deterministic tar archives preserve hidden files and nested manifests; archive
  extraction and inventory checks reject altered or unsafe bundles.
- Hosted preflight cannot claim scientific qualification. Full qualification
  requires complete method/source coverage and retained installed-wheel campaigns
  matching the release distribution, runner, dependencies and supported scope.
- Descriptive study protocols cannot emit a qualified status. Infrastructure
  errors propagate and leave work pending; declared numerical failures remain
  attempted failures.
- A new spatial study exposed roundoff asymmetry in an internally generated
  2SLS weight. Symmetrizing that generated weight preserves the strict contract
  for caller-supplied weights; an independent NumPy regression covers the fix.
- Float32 GMS projection failures now retain typed numerical availability counts;
  generic backend/runtime failures still stop execution. Additional native
  float32 diagnostics found convergence and tight reference-tolerance failures,
  recorded in the known-limitations documentation. Float64 native checks passed.
- The structural audit identified nested-source freshness as a prerequisite for
  future package extraction. Lean tooling and docs source hashes are now recursive,
  with regressions for newly created and changed nested implementation files.
- Installed preparation now detects persistent source changes across sequential
  wheel builds, inventories hidden wheel-directory files and verifies installed
  workspace payloads. Initial third-party installs use locked hashes; resume
  verifies dependency versions, not later same-version third-party payload edits.
- A further primary-source review matched unweighted OLS and its classical
  covariance, but corrected the existing HC3 approval: the original jackknife
  expression contains both a prefactor and rank-one recentering term absent from
  STATADIC's conventional sandwich. The later Long–Ervin primary manuscript supplies
  the conventional formula; independent review also matched the fixed-precision
  WLS whitening substitution. Boundary policies and reference laws remain outside
  this bounded formula correspondence.
- Direct-wheel and release-route builds initially had identical payloads but
  different ZIP timestamps. Preparation and release now use the same normalized
  sdist-to-wheel route and fixed epoch. The exact archive equality gate remains
  strict; no completed campaign was relabeled with another artifact's identity.
