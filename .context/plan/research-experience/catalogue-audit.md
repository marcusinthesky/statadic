# Scientific catalogue denominator audit

Audit date: 2026-11-04. This records source ownership and implemented adapters;
it does not assert completed evaluation, valid calibration or primary-source
correspondence beyond the separately recorded approvals.

## Historical snapshot: 2026-11-04

This checkpoint is retained evidence, not the current alpha denominator. The
2026-11-09 [whole-stack review](../research-release/tasks/alpha-review/coverage.md)
superseded its census. Subsequent corrective registration and required scope are
owned by [alpha readiness](../research-release/tasks/alpha-readiness/README.md),
its explicit scope and the canonical studies catalogue. No later adapter or
source approval is inferred from the counts below.

The checked catalogue contains **43 scientific procedure families and
191 substantive variants**: all have exact adapter method/scenario mappings,
across **75 implemented study designs**. There are 32 bounded primary-source
correspondence approvals and **159 unresolved source reviews**. Coverage remains
`incomplete`: an adapter mapping is not a completed scientific evaluation.

These figures derive from `statadic-studies check --repository .`, not a count of
notebooks or pytest files. The machine-readable authority is
`src/python/apps/studies/catalogue.json`; every mapping names exact study,
method, scenario and scope. The 2,189 public symbols and aliases retain reverse
links to 189 canonical owner records. Zero ownership dispositions are pending.
A module-level study link cannot clear a scientific variant gap.

## What the adapters executed at this checkpoint

- Fixed-design OLS/covariance, weighted regression, IV/GMM/GEL, canonical GLM,
  independent AFT, static panels and selected spatial/dyadic models use explicit
  model/DGP truths and procedure-specific inference contracts.
- Discrepancy U/V, raw/rooted and deterministic atom-mass variants use enumerated
  population functionals. Transport includes exact sphere-ground, unequal-support
  scalar quantile and finite-projection targets; fixed versus freshly drawn
  projection targets remain distinct.
- Mantel uses node permutations or joint node-bootstrap schedules, not independent
  edge resampling. DISCO/PERMANOVA and median PERMDISP retain different nulls:
  location-only is a dispersion null. Less/greater/two-sided signed-mean tests
  freeze method-specific composite null scenarios; an opposite-direction shift
  is not called power for a one-sided test.
- Selection-split and every-permutation-reoptimized energy mixtures, reoptimized
  kernel balancing and a deliberately invalid select-then-freeze diagnostic are
  distinct methods. The last is an adverse diagnostic, not valid size control.
  Unavailable legacy solver certificates remain distinct from numerical failure.
- Population median radius, PCA projector error and sampler moment discrepancy
  use nonnegative loss risks with MCSE, not signed estimator-bias labels. Sampler
  tests include shared-scale Student joint moments and ordered fixed-count
  contamination, rather than only marginal histograms.

## Boundaries preserved in the denominator

The native `bootstrap_mixture_energy_interval` keeps supplied weights fixed across
within-group resamples. A dedicated fixed-weight study now covers that procedure;
its source correspondence and full retained evaluation remain pending. A separate
variant records the genuinely fully reoptimized energy-optimum percentile
composition, which calls the native batched optimizer for the original and every
bootstrap finite-law distribution and uses an independently minimized population
quadratic. This additional variant raises the denominator from 190 to 191; it does
not substitute one procedure for the other. Interior positive and zero-boundary
optima remain distinct scenarios.

Weighted empirical atom functionals and optimized-mixture tests do not silently
cover the public weighted candidate-mixture energy evaluation door. The Gaussian
positive-part boundary-tail helper with known SE does not cover the correlation-
gap kappa estimator, estimated delta SE or Jacobian concentration pipeline. The
lower-boundary variant is narrowed to the public supplied-value/known-SE helper;
its mapping overlaps the existing helper variant rather than adding independent
evidence for a fitted pipeline that is not exposed by that public door.
Uncorrected eta0 indicator GMS is not RMS/Table-I certification; Wolak's use of
simulated chi-bar calibration is separate from direct approximation accuracy;
the latter is now evaluated against identity-covariance binomial weights. Float32
QLR projections can return structured native solver-unavailability counts, which
remain attempted numerical failures rather than successful procedures. Rooted discrepancies have nonlinear population targets; no unbiased-
root conclusion is inferred from a U-statistic identity.

Configuration selectors, source correspondence, retained evaluation and release
qualification remain separate. The one-way DISCO/PERMANOVA representative received
a bounded primary-source approval; PERMDISP, population and resampling obligations
retain their separate unresolved reviews. Bibliographic metadata alone never grants source
approval. The 170,000 retained initial source-only replications cover four older
designs; their completion does not imply execution of all 75 current designs or
installed-wheel release qualification.

## Remaining scientific programme

The last adapter integrations add fixed-moment HAC Wald tests, fixed-supplied-weight
mixture bootstrap intervals and a shared-data spatial-survival pilot with fixed
and adaptive integration methods. The pilot retains actual censor counts,
integration budgets, refinement histories and unavailable procedures. It has not
been runtime-validated at the full evaluation budget; registration does not imply
that a 10,000-replicate campaign is practical or completed.

Primary-source correspondence, current installed-wheel evaluations and
configuration-specific numerical qualification remain substantial open work.
The source decisions and exclusions are retained in
[the review record](tasks/studies/tasks/sources/decisions.md).
Numerical helpers and supplied-empirical-objective solvers retain explicit
numerical/domain/identity contracts rather than artificial Monte Carlo studies.
