# Unify the public research workflow

## Goal

Implement the accepted audit of both November 10 workflow transcripts and typing
feedback. Regression, Ordination, Estimand, Hypothesis and Report orient the public
workflow. Preserve independent numerical owners and scoped scientific evidence.

The [design](design.md) owns interfaces, [dispositions](proposal-dispositions.md)
accounts for proposals, and [validation](validation.md) records execution.
The existing [alpha task](../research-release/tasks/alpha-readiness/README.md)
owns release qualification; this plan does not duplicate its gates.

The coordinator owns shared contracts, architecture, inventories and serialized
verification. Three agents own structural/spatial/survival workflows,
ordination/estimands, and inference/references. Each patch receives independent
review. Follow-ups remain separately visible backlog, outside the required alpha
repair slice. Existing completed reviews remain tied to their original source.

## Acceptance

- [x] Complete the required API, typing, inference and hygiene repairs.
- [x] Verify public workflows, documentation and exact reference execution.
- [x] Review independently and verify candidate components, retaining aggregate limitations.
- [ ] Complete separately scoped follow-ups when their scientific triggers are met.
