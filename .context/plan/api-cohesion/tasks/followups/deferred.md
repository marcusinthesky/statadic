# Deferred work and reopening criteria

These are explicit follow-ups, not new prerequisites for the current API repair.
The disposition ledger owns the original proposal IDs. Reopen each item through a
separate authored task with its mathematical contract and acceptance evidence.

| Work | Trigger and required evidence |
| --- | --- |
| Remaining Estimand quantities | A real consumer for energy, MMD or association composition; retain V/U estimands, scaling, tails, singleton domains and exact schedules. |
| PERMDISP grammar integration | A representation preserving spatial medians, negative inertia, bias correction and the existing full-model radius-residual permutation law. |
| Partial Mantel inference | An explicit justified null and calibration; descriptive residualized correlation is not node-permutation inference. |
| Generic multiplicity | Supported marginal reference contracts; never replace paired joint Sharpe stepdown draws. |
| Metric graph production memory | Representative corpus, actual sustained process/workload memory measurements and independent matched reference output. Current workflow remains experimental. |
| Constrained mixtures and diagonal innovations | Consumer requirement plus separately verified model, rank, boundary and inferential assumptions. |
| Boundary QLR/bootstrap | A justified boundary law and failure-inclusive simulation; no generic chi-square or graph bootstrap substitute. |
| Differentiated barycentres | An explicit optimal-solution derivative contract including active sets and failures; no inference from finite solver-iteration AD. |
| Additional spatial families/multiple graphs | Actual effect/innovation model and independent references for each supported parameterization. |
| Absorbed unit slopes | Identifiability, degrees of freedom and prediction contract, with independent panel comparisons. |
| Penalized GAM | Explicit penalty/selection/covariance design, distinct from existing unpenalized spline bases. |
| String graph codebooks | Stable train/query/resampling/artifact identity across rosters; no independent automatic encodings. |
| General test alternatives and chi-bar laws | An implemented procedure and its own mathematical/statistical validation. |
| LIML, FE-Poisson and additional survival laws | A concrete required workflow, native fit/inference contract and matched external oracle. |
| Retire api.embedding | Owner decision: retain until actual downstream import migration; replacement signed-spectrum consumer fixtures already pass. |
| Remaining selector/shape refinements | Tighten only demonstrated closed native choices with negative typing fixtures. Extend existing shape audit beyond the measured two-module sample; three measured ground-distance functions remain unchecked. No blanket conversion or cast-count target. |
| Standalone inferential procedures | [Task](tasks/standalone-procedures/README.md). Owner decides the host for equivalence, mixture, Sharpe, moment-inequality, Wolak and kappa procedures; adapters retain native evidence and laws. |
| Shipped variants without a reference | [Task](tasks/reference-gaps/README.md). A matched installed peer or a recorded reason; exact executed nodes only. |
| Lifecycle contract test | [Task](tasks/lifecycle-contract/README.md). No scientific trigger; one enumerating test over host results. |
| Directional coefficient tests | [Task](tasks/directional-tests/README.md). A workflow needing one-sided inference, with a directional proposition and signed statistic. |
| NB2 log likelihood | [Task](tasks/nb2-log-likelihood/README.md). A log-beta accurate in both precisions across the dispersion range; then assert the likelihood against statsmodels. |
| Publication hygiene | [Task](tasks/publication-hygiene/README.md). Owner decisions on history, private paths, scans and internal identifiers before any public push. |
| Full alpha release | Existing source fidelity, scientific campaigns, large-survival and exact archive requirements remain with alpha-readiness. No approval transfers from this repair. |
