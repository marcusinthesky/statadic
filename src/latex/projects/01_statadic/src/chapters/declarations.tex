\section*{Software availability}

STATADIC \jcvalue{statadic-version} is distributed under the Apache License 2.0 and
requires Python~3.13 and JAX. The source repository at
\url{https://github.com/marcusinthesky/statadic} contains the library, tests, Lean
development, documentation and this paper; it is access-restricted at the time
of writing. The results were generated from a working tree based on revision
\texttt{\jcvalue{revision}} with locked Python environments. The analysis and
listing source fingerprint is \texttt{\jcvalue{analysis-hash}}; the
package source
fingerprint is \texttt{\jcvalue{package-hash}}. Full SHA-256 fingerprints are
recorded in \texttt{src/generated/provenance.json}. The command
\texttt{just latex::generate 01\_statadic} regenerates every reported number, table
and figure, and \texttt{just latex::build 01\_statadic arxiv} rebuilds the
manuscript offline from a vendored TeX bundle.
