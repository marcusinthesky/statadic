# Measurement boundaries

The CLI and measurement helpers import no JAX. The orchestrator launches fresh
CPU processes with explicit float32/float64 and thread/cache settings. Workers
prepare deterministic host fixtures; adapters call actual STATADIC owners. Numerical
library modules remain caller-precision governed. Existing algorithms are neither
rewritten nor optimized by this application.

Campaigns retain source/lock identity, environment, raw session samples, separate
memory-worker records, logs and exact file inventories. Partial failures stay
failed and cannot be compared as complete campaigns. Reports are written outside
retained evidence. Archives include every retained file including hidden traces.
Hardware comparisons are descriptive; timing assertions do not gate correctness.
Scientific studies and implementation refinement remain separate consumers.

Independent NumPy numerical witnesses gate measured results outside timing.
Cold combined JIT calls each receive a fresh worker and are not reconstructed
by summing separately measured phases. Synchronized compiled execution and host
materialization retain distinct timings and scope labels.

The current-wheel reference lane has separate records from native revision
comparisons. It launches each implementation/case/session in a fresh isolated
process and verifies the candidate's installed payload against the actual wheel.
Reference processes import no JAX. Its verifier owns numerical output agreement,
exact scope/lock/harness identity and per-session warm/whole-RSS ratios. Pilot
observations mint no qualification records. Full qualification requires every
reviewed workload subcase and both required resource wins in all three sessions;
missing implementations remain explicit failures.
