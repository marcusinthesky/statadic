# One workflow, many models

**Align → Specify → Estimate → Inspect → Diagnose → Predict or infer → Report.**

Align observations and roles. Choose a model and supported components.
`model.estimate(data)` prepares the design from the training rows, then estimates;
the result retains both. Check validity, request explicit diagnostics with
`result.diagnose(...)`, then predictions or inference. Report assumptions.

The [core concepts](../concepts/index.md) explain models, quantities, hypotheses and reports.
Numerical availability does not establish scientific assumptions.
