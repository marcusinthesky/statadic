# STATADIC

Fit a familiar model, explore its diagnostics and carry the results through to
a report. Start with a [first regression](start/first-regression.py), then use
the [method map](methods.md) to find an analysis for your question.

The site separates worked analyses, practical tasks, explanations, API contracts
and evidence. Each method's reference page states its assumptions and limits.
