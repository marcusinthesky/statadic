# Derived views

`just sync` refreshes these views; `just check` rejects stale output. The ignored
SQLite index is disposable. Frontmatter and authored bodies remain canonical;
Insitu owns only the regions between its markers.

The reference index lists immediate records. Each plan exposes immediate tasks;
the root roadmap lists plans. Terminal work is counted rather than copied into
every parent. Reading deeper means following one child link, keeping context small.

Backlinks derive from explicit canonical repository-relative file paths in `links`.
Use a full file path without `./`, traversal, URL encoding, queries or fragments.
Body links retain ordinary URL and section syntax.

SQL and templates describe project policy; Insitu supplies the independent query
and materialization engine. Work items always contain one children region, so
synchronization never inserts or removes record structure.
