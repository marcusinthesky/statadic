# Document schemas

`just check` selects a schema by each record's path. Plans and tasks share one
work-item contract; their `type` must assert the physical role. References use
flat CSL metadata, with their citation key derived from their directory name.

Context entry points and records have a 1,500-token budget. The product README
uses the separate 6,000-token overview contract for its examples and evidence
table, alongside the docs application's 850-word limit. Keep supporting detail
in linked files beside the owning record. Schematter checks document shape;
the workflow helper checks containment, links and honest completion.
