# Document schemas

`just check` selects a schema by each record's path. Plans and tasks share one
work-item contract; their `type` must assert the physical role. References use
flat CSL metadata, with their citation key derived from their directory name.

Entry points and records have a 1,500-token budget. Keep supporting detail in
linked files beside the owning record. Schematter checks document shape; the
workflow helper checks containment, links and honest completion.
