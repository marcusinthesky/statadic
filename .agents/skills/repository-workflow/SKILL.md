# Repository workflow

Read the root README and the relevant local README before changing records.
Use `just --list` to discover the installed workflow and language commands. Create
records through their commands, edit canonical metadata, then run `just sync`
when available and `just check`. Keep task parents terse and store detailed
evidence in linked records. Verification establishes only what the actual
command output supports; record incomplete or inconclusive checks honestly.
